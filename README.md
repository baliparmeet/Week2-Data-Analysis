
# Week 2: Data Analysis Using Python and SQL

## Project Overview
This project focuses on practising basic data analysis techniques using Python, Pandas, and SQL. A small sample sales dataset was used to explore product revenue, customer purchases, and order information.

## Objectives
- Load and inspect data using Pandas.
- Check for missing values and duplicate records.
- Calculate revenue and group data by product or category.
- Sort data and create a correlation matrix.
- Use SQL queries to filter, sort, and summarize orders.
- Find top customers and average order value.
- Combine customer and order information using SQL joins.

## Tools Used
- Python
- Pandas
- SQL Server-compatible SQL queries
- Excel
- VS Code

## Files Included
- `sales_data.csv` — Sample sales dataset.
- `week2_analysis.py` — Python practice exercises.
- `week2_queries.sql` — SQL setup script and analysis queries.

## Key Findings
- Total revenue: 2,950
- Average order value: 590
- Total orders: 5
- Highest-revenue product: Sunscreen (2,000)
- Top customer by revenue: Aisha (1,600)
